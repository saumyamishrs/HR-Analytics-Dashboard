# HR Analytics Dashboard (Power BI)

## 📌 Project Overview
This **Power BI Dashboard** is designed to analyze organization-wide **Employee Attrition** and key workforce dynamics. By leveraging data-driven insights, this project uncovers the root causes behind employee turnover, enabling HR leaders to make informed, strategic decisions to improve workplace retention and employee satisfaction.

---

## 📊 Core Dashboard Features

| Feature / Domain | Description & Metrics Covered |
| :--- | :--- |
| **High-Level KPIs** | Provides a snapshot of the workforce: **1.47K Employees**, **237 Attritions**, **16.1% Attrition Rate**, **37 Average Age**, **\$6.5K Average Salary**, and **7.0 Average Years** of service. |
| **Demographic Attrition** | Breaks down employee turnover by **Age Groups** (revealing peaks in the 26–35 bracket) and **Gender** (150 Male vs. 87 Female). |
| **Education & Role Analysis** | Visualizes departure volume based on academic background and highlights turnover across specific roles like **Laboratory Technicians** and **Sales Executives**. |
| **Financial & Experience Trends** | Tracks attrition across monthly salary tiers (showing severe turnover for salaries under **\$5K**) and maps it against years spent at the company. |
| **Department Slicers** | Features interactive filtering to view tailored metrics for **Human Resources**, **Research & Development**, and **Sales** departments. |

---

## 🛠️ Tech Stack & Methods
* **Power BI Desktop:** Used for data modeling, dashboard interface design, and creating interactive charts.
* **Power Query:** Utilized for data cleaning, column profiling, and type transformations.
* **DAX (Data Analysis Expressions):** Used to calculate custom measures and dynamic KPIs (e.g., Attrition Rate).

---

## 📈 Top Business Insights
* **Compensation Pressure:** The vast majority of departures (**163 out of 237**) occur among staff earning **Up to \$5K/month**, pointing to a critical need to evaluate entry-level pay structures.
* **Early-Career Turnover:** Employees aged **26–35** represent the highest attrition risk demographic with **116 departures**.
* **High-Risk Roles:** **Laboratory Technicians (62)** and **Sales Executives (57)** exhibit the highest volume of turnover, making them primary targets for tailored engagement strategies.

## 🚀 How to Run and Interact with the Dashboard
1. **Clone** or download this repository to your local computer.
2. Make sure you have the latest version of **Power BI Desktop** installed.
3. Open the provided `.pbix` file.
4. Use the dynamic department buttons at the top to filter and explore the live data.
